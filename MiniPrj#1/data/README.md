### 데이터셋
#### 비정제 텍스트 데이터셋
 1. 일상대화 한국어 멀티세션 데이터(AI Hub)
  - 다운로드 링크(https://aihub.or.kr/aihubdata/data/view.do?srchOptnCnd=OPTNCND001&currMenu=115&topMenu=100&searchKeyword=%ED%95%9C%EA%B5%AD%EC%96%B4+%EB%A9%80%ED%8B%B0%EC%84%B8%EC%85%98+%EB%8C%80%ED%99%94&aihubDataSe=data&dataSetSn=71678)
  - 데이터셋 크기: 61,553
  - 일상음성대화 텍스트 변화 데이터, 발화자 지역 분포: 4개 지역 별 인구분포 기준 10% 오차 내 모집, 전문지식 답변 수: 한 세션 당 최소 1번, 전문지식 출처 수: 한 세션 당 최소 1번, 성별 : 한 성별 최대 60%, 연령대 : 한 연령대 비율 최대 40% 넘지 않음  

 2. everytime_ai(Github)
  - 다운로드 링크(https://github.com/Dumul-KJH/everytime_ai/tree/main)
  - 데이터셋 크기: 26,643
  - KAIST 에브리타임 대학생 커뮤니티 게시물 텍스트, 2022년도 대화, 2023년도 대화 


 3.  kor_unsmile(Hugging Face Datasets)
  - 다운로드 링크(https://huggingface.co/datasets/smilegate-ai/kor_unsmile)
  - 데이터셋 크기: 18,742
  - 인터넷 커뮤니티 텍스트, **혐오표현(다중 레이블):** 10,139개, **악플/욕설:** 3,929개, **Clean (정상 발화):** 4,674개
